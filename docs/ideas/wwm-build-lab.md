# WWM Build Lab

## Problem Statement

How might we help serious Where Winds Meet Global players turn a large gear inventory into a trustworthy build decision without confusing theoretical calculator output with an in-game parse?

## Directions Explored

1. **Spreadsheet workbench** — maximum density and fastest comparison, but weak game identity and intimidating onboarding.
2. **Guided build wizard** — easiest to learn, but too slow for repeated gear optimization.
3. **Game-native command center** — dense tools organized into stable workspaces with strong WWM identity.

## Recommended Direction

Build the game-native command center. It combines the step clarity of WWM Stats Calculator, the focused calculation surfaces of Where Winds Math, and this app's deeper inventory/optimizer features.

The product is not a dashboard and not a landing page. It is a persistent four-workspace tool: Arsenal, Build, Combat, and Optimize. The same selected character, scheme, tier, equipped gear, and assumptions remain visible across workspaces through a compact context bar.

## Key Assumptions to Validate

- Global optimizers prefer dense, persistent context over a multi-step wizard.
- Gear decisions are the most frequent task, so Arsenal is the default workspace.
- Players understand results better when formula ceiling, modeled estimate, and recorded parse are visually separate.
- Game-native art direction increases trust only if data remains highly legible.

## Product Scope

- Arsenal: inventory, equipped slots, filters, comparison delta, import/add/edit.
- Build: path, weapon pair, sets, Inner Ways, ring and calibration.
- Combat: assumptions, reference rotation, formula output, stat table and damage distribution.
- Optimize: graduation overview and all existing analysis tools.

## Not Doing

- No new formulas or game data during the UI rebuild.
- No marketing homepage.
- No decorative wuxia effects that reduce readability.
- No new UI framework.
- No invented in-game parse value.
