HOW IT WORKS

Tracker rules

  • Slots 1–4 track Gold pity independently up to 90.
  • Modeled quality rate starts at Blue 82% / Purple 15% / Gold 3%, with the original calculator's soft-rate tiers after 30 and 60.
  • Each reforge advances the next inactive slot by about 3.33%, with the original calculator's early-activation model.
  • Slot 5 becomes Gold automatically when activated and is not rerolled.
  • Locking 0/1/2/3 slots costs 1/2/5/10 Taiyi Stones per reforge.
  • Everything is stored only in this browser. Use Edit state to enter your real in-game pity manually.
